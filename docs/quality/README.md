# 离线笔记质量工具

状态：G4 开发工具，本地源码验证；没有接入产品菜单，没有调用真实模型或发布新版本。
案例是本项目原创的无隐私合成文本，不来自用户视频，也不复制竞品提示词。

## 能做什么

12 个固定案例覆盖概念、步骤、多人观点、否定、数字与单位、公式、代码、重复口语、
双语术语、字幕缺口、长时间轴尾部及资料中的恶意指令。每例标注 3 个必要信息点、
原始分段、期望相交段、人工参考正文和字面规则。六个现有内置模板全部覆盖。

运行于仓库根目录，使用已经安装的 `.venv`：

```powershell
.venv\Scripts\python.exe -m scripts.evaluate_notes
.venv\Scripts\python.exe -m scripts.evaluate_notes --output .test-tmp/g4-reference.json
```

保存路径的父目录需已存在，目标文件必须不存在。默认参考轨直接复用现有模板外壳、
单次占位符替换、Frontmatter、转录 hash、SRT 导出/解析与时间范围定位。
报告只含已知案例 ID、检查代码、字面信息点数量和内容 hash，不含输入或成稿正文、路径。
`manual_review=not_scored` 始终表示尚未人工评分。

显式比较由这 12 个合成输入产生的待测成稿：

```powershell
.venv\Scripts\python.exe -m scripts.evaluate_notes --notes-dir .test-tmp/synthetic-notes
```

该目录需要 `<case-id>.md`，只读固定 12 个名称，不遍历用户工作区或 Vault。
缺失、不可读或不安全的文件直接失败，不能退回参考答案。案例通过稳定 ID 选择现有模板，
Frontmatter `template` 与生产笔记一样使用模板名称。输入限定本地合成字幕，元数据检查要求
`platform=local` 和 `transcript_source=subtitle_import`，不适用于任意平台历史笔记。

## 检查边界

- 字面信息点可接受标注的同义表达，标题/顺序不做全文快照匹配。规则全部通过只能证明
  标注的字面和格式条件，不能证明摘要正确、完整或没有幻觉。关键词堆砌同样可能通过。
- 数字、单位、公式、代码、否定只检查明确标注的字符串；事实含义、相反观点和未标注的
  外部补充须用[人工表](manual-review.md)判断，不给出综合“准确率”。
- 时间检查验证 `[]` 中 `MM:SS` / `HH:MM:SS` 及范围的合法性和转录段相交；
  不证明该句观点与此时段语义一致。代码围栏和行内代码不当作时间引用。
- 附件只检查内联 Markdown 图片路径安全和声明集合的一致性，不验证图片文件存在或内容。
  教程案例的 `frames/example.png` 只是声明，不提供真实图片。引用式图片和 HTML 图片拒绝检查，
  返回 unsupported/unsafe，避免默许没有检查过的表示。
- 这是有限的 Markdown 识别器，不能代替浏览器安全渲染测试；实际阅读器/恢复等证据见 G0–G3。
- `long-timeline-tail` 只有 3 段，末段在两小时处。它检验尾部锚点遗漏和小时格式，
  不构成长文本截断、真实长视频性能或模型上下文长度验收。
- `untrusted-instructions` 只证明资料和占位符被当成字符串处理；没有对任何真实模型做
  提示注入安全评测。

## 复现与失败

案例文件在 `tests/fixtures/note_quality/`。修改规则、参考正文或段落会改变 `case_sha256`；
修改成稿会改变 `note_sha256`；原始分段身份使用 `transcript_sha256`。比较时保留这三个值，
不要跨不同案例版本直接比较。没有重试、网络请求、模型实例化或自动补答。

退出码：0 为本次规则检查通过，1 为案例/成稿/资产检查失败，2 为参数或输出不可用。
错误只返回固定代码；输出使用独占新建，拒绝已有文件、硬链接输入及链接/重解析路径组件。
路径检查不抵御同时改写文件系统的特权进程，使用无人并发修改的隔离目录。
