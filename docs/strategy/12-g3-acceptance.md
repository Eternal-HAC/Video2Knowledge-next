## 已实现

- `backend/transcript.py` 增加有序时间/文字的稳定 SHA-256 与时间相交定位。
  数值 1 与 1.0 等价；内容、时间或段序改变即改变版本。同时间段保留独立索引。
- 新增只读 `GET /api/task/{task_id}/transcript-context`，按秒传入 start/end，
  每页最多 100 段，支持 offset、预期 transcript_hash/note_hash。点采用半开区间，
  零长段仅在同一点命中；不寻找最近句。返回匹配/部分越界/越界/缺口状态与已保存范围。
- 复用 G2 转录校验及 G0 路径检查，拒绝不可安全读取、缺失或损坏的产物；
  错误固定脱敏，不触发下载、ASR、LLM、飞书或写回任务清单。
- 结果区新增「查看原转录」与可按键操作的正文时间戳。原文使用 textContent，
  跳过代码、公式、链接和隐藏区域，最多启用 200 个时间戳按钮；没有时间戳时可手动输入范围。
- 面板展示保存范围、多 P 累计时间轴和任务媒体是否仍保留；支持分页、关闭/Escape、返回原按钮。
  显示“按时间定位，未验证观点正确性”。读取失败清空旧结果，提供显式重读入口。
- 以 Markdown hash、转录 hash、阅读版本与请求序号拒绝混合版本、旧分页和迟到响应。
  完整源 Markdown、复制和导出不写入阅读标记，仍是一条视频一篇 Markdown。
- 发现外部改写笔记后历史可能使用内存旧正文，补可选 `GET /api/task/{id}?refresh_note=true`。
  历史打开显式现读 notes.md；失败不返回缓存旧正文。正常轮询和 MCP 默认行为保持不变，
  不修改原任务缓存或清单；已有转录下载 API 结构不变。

## 限制与下一步

- 时间命中只提供核对入口，不证明观点有据、转录完整或 ASR 准确；hash 表示读取内容版本，
  不证明该转录从生成笔记以来从未被外部替换。没有观点级引用、语义检索或自动模型校验。
- 按现有方括号时码识别；被拆到多个行内节点的时码不启用按钮，可手动输入。
  多 P 沿用已有累计时间轴；未保存可靠逐 P 偏移，因此不新增视频时间跳转或本地播放。
- “媒体未保留或不可读”不等于证实已被删除。路径检查沿用现有边界，不宣称对恶意并发文件替换具备沙箱保证。
- 每次定位仍校验当前完整转录和笔记，未建立数据库/持久映射；超长任务性能留给测量决定，
  不把本轮合成短任务验收扩大为任意长视频性能保证。
- 下一候选是 G4 的离线质量样例与诊断导出规格。真实模型评测、Host/Origin 审计、
  打包验收与发布仍需独立限定范围和授权；本轮没有开始 G4/G5。
