## 边界

按用户「继续」执行既定 G3。主对话直接开发，保留当前分支全部未提交改动。
仅修改转录定位工具、只读 API、结果阅读器、对应测试与文档。不安装依赖、不提交、不打包、不发布，
不调用真实模型、下载、ASR、凭据或飞书。G4/G5 不在本轮范围内。

## 实现合同

1. 转录 hash 来自有序的时间/文本规范 JSON，数值 1 与 1.0 等价，修改文字、时间或段序均改变 hash。
   不写回旧任务，不增加模型调用。每个命中段使用有效转录段的顺序索引，同时间段不合并。
2. 只读 `GET /api/task/{task_id}/transcript-context` 按秒区间定位。点使用半开区间
   `start <= t < end`，零长片段仅在同一点命中；范围返回真正相交的段，不自动找最近句。
   每页最多 100 段，可继续读取。区间越界/覆盖不全、无匹配、缺失/损坏转录分别可解释。
3. 响应包含转录 hash、当前笔记 hash、时间轴范围、媒体是否仍保留，以及分页信息。
   后续请求带预期 hash，文件变化返回 409，不混合两个版本。笔记 hash 按完整 Markdown 计算；
   前端每次使用新的阅读版本令牌，迟到响应不得覆盖新笔记或新选择。
   历史打开通过已有任务端点的可选 `refresh_note=true` 读取当前 notes.md，原轮询默认行为不变；
   读取失败不退回缓存旧正文。原文失败面板提供显式重新读取笔记入口。
4. 时间戳按钮只来自安全渲染后正文的文字节点；跳过代码、公式、链接和隐藏内容，最多建立 200 个。
   笔记无时间戳时仍可输入时间范围核对。原转录以 textContent 展示，不解释其中 HTML。
   阅读对照只发 GET，不改变 Markdown、导出、任务、模板或历史格式。
5. 面板明确表示“按时间定位，未验证观点正确性”。B 站多 P 使用已合并累计时间轴，
   不猜测逐 P 跳转偏移。无可靠映射时不新增平台时间跳转。媒体未保留与转录存在可同时成立，
   不把文件缺失断言为用户删除；损坏或缺失转录不触发重新处理。
6. 面板可关闭并返回触发位置；390px 纵向阅读，无页面横向滚动；键盘可打开、加载更多和返回。
   错误固定脱敏，不回显磁盘路径。已有转录下载 API 保持结构不变。
