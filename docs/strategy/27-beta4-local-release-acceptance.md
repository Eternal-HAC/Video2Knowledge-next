- G0 进度/结果、G1 阅读/导出、G2 显式恢复、G3 原转录对照、历史刷新五套脚本，各通过 1440×900、1024×768、390×844 与亮/暗/系统主题九组组合。键盘焦点与无页面级横向滚动由脚本断言。全部使用合成数据，无真实模型调用。

- 更新中英文 README：首页、历史、模板截图来自 capture 脚本，进度/结果来自 G0 脚本。检查了桌面首页、进度/结果和移动暗色截图，没有真实 Key、私人路径或用户任务。
- 打包版分别在只设置新、只设置旧 workspace 环境变量的隔离工作区通过客户端验证。两次均检查健康、六模板、静态资源、Host/Origin/metadata 拒绝、同源字幕上传、原生 BackendClient HTTP，以及无 Origin/同源 Origin 两次真实 MCP SDK SSE 会话。
- 打包原转录区间 API、恢复信息和未知提交查询通过。只读取恢复摘要，没有发起真实笔记重新生成。
- 现有 history smoke 在明确 `ExpectedVersion=1.0.0-beta.4` 下通过：两条合成历史分页、收藏重启持久化、按需读取、平台识别及已有转录提示。脚本名称里的 beta3 为既有测试名称，不代表本次测的是旧 EXE。

## 构建与清理观察

PyInstaller 主体约 121 秒完成，之后副本/摘要处理与一次独立 Python 文件打开出现等待，最终自行完成。原因未确认，没有关闭或绕过安全软件。外层展示日志的命令受构建脚本切换当前目录影响，首次尾读路径不正确；随后从绝对仓库位置读取到完整构建成功记录，并独立核对资产。

原递归清理命令被自动审批拒绝，未执行删除。随后先只读审计，再采用固定目标、有限文件名白名单、身份复查、逐文件删除和空目录移除，成功清理合成工作区，无递归删除。原生 smoke 自行清理各自临时目录；两份合成 WAV 已删除。验收根目录下不再有 WAV，候选目录所属进程数为 0。无 llm_keys.json，任务与日志凭据模式审计通过。

保留源码快照、浏览器合成证据、工具日志、EXE 和校验文件以供复核，不把未跟踪的忽略目录当成 Git 已提交内容。
