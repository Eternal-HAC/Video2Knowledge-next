## 真实浏览器验收

复用仓库已有 Chrome/CDP 工具，不新增依赖。在本轮隔离 workspace 服务（本机 8018）上运行：

```powershell
node scripts/verify_g1_browser.mjs http://127.0.0.1:8018/ .test-tmp/g1-acceptance-20261023
node scripts/verify_g0_browser.mjs http://127.0.0.1:8018/ .test-tmp/g1-acceptance-20261023/g0-regression
```

9 组矩阵为 1440×900、1024×768、390×844，各配亮色、暗色、系统主题。系统主题在本轮模拟暗色系统外观，不代表所有 OS/浏览器组合均已验收。

G1 检查覆盖：

- 初屏来源与开始按钮位于可见范围；首页、阅读区和转录视图无页面级横向滚动。
- 六模板及合成自定义模板选择、select 同步、所选卡片焦点、预览键盘开合、管理设置焦点返回、仅转录隐藏选项。
- 重复标题、恶意标题、预占 ID、脚本及事件属性清理；标题独立跳转且不被顶栏遮挡。
- 跨加粗匹配、英文大小写、正则特殊字符字面查找、零结果、前后跳转、Enter/Escape、Tab 和可见焦点。
- 公式与图片节点内容保持一致；清除后正文一致；复制及 HTML 导出不含搜索标记。
- 当前匹配高亮在三种主题下均达到至少 4.5:1 的文字对比度。
- 超过 200 处匹配时限量提示；再次打开笔记/转录时旧状态清除。

真实后端请求仅允许 health、空历史 tasks 与真实 note-templates；集成、Key/模型/登录状态与笔记结果均为合成 fixture。下载响应也为 fixture，只验证前端响应处理，没有对外创建文件或调用系统默认程序。所有非白名单请求被阻断，结果中违规请求及未捕获异常为空。
